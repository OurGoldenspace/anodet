# Investor demo — 3 to 5 minutes

The aha is Reuse. Engine 31 has no remembered case. You save one. Engine 74 leads with it. NASA C-MAPSS FD001 is a labeled demo fleet, not a customer.

If Grok is unset, the template draft still works. Say “the server kept the manual order.”

## 1. Problem — 20 seconds

“Your machines generate data. Your technicians generate knowledge. Today those two never meet. The cheap check that worked last month dies with whoever was on the job.”

## 2. Existing workflow — 20 seconds

“The next engine with the same heat and pressure marks starts from the expensive OEM page again. Spreadsheets and PDFs do not travel with the signature.”

## 3. Product — 20 seconds

Open http://localhost:3000.

“Anodet is procedure memory. Detect, investigate, resolve, remember, reuse. We do not sell a failure forecast. We sell the case the next asset can reuse.”

## 4. Input — 30 seconds

Sign in with your name and the shop passphrase.

Click **Use the NASA demo fleet**.

Say: “This is NASA C-MAPSS FD001. Not a customer. A shop file is the buyer path.”

If a leftover case is on Engine 31: **Sample shop → Reset demo to empty**.

## 5. Core workflow — 60 seconds

1. Fleet (Detect) already highlights Engine 31. Click it if needed.
2. Stay on the case pane. Point at **Detect · evidence** (exhaust / NRf / bleed marks in words, not a percentage).
3. Point at **Investigate · procedure**. The manual books a borescope first.
4. Click **Draft a reorder with Grok**. Wait. The server rejects invented parts.
5. Enter a cause, e.g. `Hot-section wear confirmed on the cheap checks`.
6. Outcome: **Yes — cheaper order worked**.
7. Click **Remember this case**.

## 6. Result — 60 seconds

Click **Open Engine 74, same signature** (or pick Engine 74 in Detect).

**Reuse · shop memory** now leads. Same sensors, same direction. The manual is unchanged.

“That strip at the bottom is shop memory. It lives in SQLite. Restart the API and it is still there.”

## 7. Business impact — 30 seconds

Open **Sample shop → Investor brief** only if they ask.

“First buyer is a marine-diesel or millwright lead who can say yes this month. The moat is their reviewed cases, not Isolation Forest. NASA lead-time numbers are this file only — not field accuracy.”

Optional shop proof: **Bring shop file** → `data/demo/marine-diesel-sample.csv` → Fit → same three blocks.

## 8. Expansion — 20 seconds

“Next: a real passphrase on HTTPS, then a second shop id. Later hours already append without a refit. We do not need Kafka to take a pilot.”

## If something is slow

- API still loading: wait for “Loading the NASA demo fleet…”
- Draft sits: say the server is checking the manual. Template fallback is honest.
- Engine 31 already remembered: Reset demo to empty, then start again.
- Wrong desk: **Change start** → NASA demo fleet.
